# 記賬本 · 香港

香港支付方式全覆蓋的個人記賬工具。單頁 PWA，可安裝到手機主畫面，離線可用。

## 功能

- **18 種預設錢包**：現金、八達通、手機八達通、八達通銀包、PayMe、AlipayHK、WeChat Pay HK、BoC Pay、Tap & Go、雲閃付、轉數快、匯豐、中銀、恒生、Mox、ZA、信用卡
- **兩層記賬模型**：資金來源（錢包）與支付渠道分開記錄，避免重複計算
- **記賬**：數字鍵盤輸入、自然語言一句記賬、常用範本、收入／支出／轉賬三種記錄
- **分類**：35 個預設分類，可自訂新增、改名、換圖示
- **結算**：月度收支結算、分類結算、錢包期初期末結算、預算進度、對賬、朋友分賬（AA，自動計算最簡轉賬方案）
- **圖表**：環形圖、柱狀圖、折線圖、堆疊柱、日曆熱力圖、桑基圖
- **同步**：以 GitHub 私有 Gist 作跨裝置同步，資料不經第三方伺服器
- **其他**：外幣匯率換算、標籤、密碼鎖、深淺色主題、JSON 備份、CSV 匯出

## 使用

1. 用瀏覽器開啟網址
2. iOS／Android 選單選「加到主畫面」即可像 App 使用
3. 跨裝置同步：設定 → 設定同步，輸入 GitHub Fine-grained token（只勾選 Gists）並建立 Gist

## 技術

純靜態：HTML + CSS + 原生 JavaScript，無框架、無外部 CDN。圖表為手寫 SVG。資料存於瀏覽器 localStorage。
